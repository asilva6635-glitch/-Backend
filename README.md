# Proyecto HelpDesk Alexandra

Este repositorio contiene el **Backend API** para el sistema de Mesa de Ayuda (HelpDesk).  
Su objetivo es gestionar incidentes, usuarios y solicitudes de soporte técnico de manera eficiente.

## 🚀 Características principales
- Gestión de tickets de soporte (crear, actualizar, cerrar).
- Base de datos SQLite para almacenamiento.
- Endpoints REST para interacción con clientes.
- Configuración inicial con Node.js y Express.

## 📂 Estructura del proyecto
- `src/` → Código fuente del servidor.
- `package.json` → Dependencias y scripts.
- `package-lock.json` → Bloqueo de versiones.
- `base de datos.sqlite` → Base de datos del sistema.
- `README.md` → Documentación del proyecto.
